# 💻 Archita Srivastava – Portfolio Website

This is my responsive portfolio website showcasing my background, skills, projects and experience as an aspiring full-stack developer. Built using HTML, CSS, and JavaScript, the design uses a clean indigo theme with light and dark modes and a mobile-first layout.

## 🔥 Features

- Smooth scrolling navigation with active section highlighting
- Light and dark theme toggle (remembers your choice)
- Responsive layout for all devices with a mobile menu
- Skills grouped by backend, frontend, tools and CS fundamentals
- Project cards with tech tags, live demo and GitHub links
- Experience section and contact section with social links
- Accessible: skip link, semantic HTML and visible keyboard focus

## 📁 Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
