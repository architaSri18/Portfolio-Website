# Archita Srivastava – Portfolio Website

Personal portfolio for **Archita Srivastava** — Full-Stack Developer (Node.js, TypeScript, React). A responsive single-page site with a clean indigo theme, light and dark modes, and a mobile-first layout. Built for [GitHub Pages](https://pages.github.com/).

## Live site

[https://architasri18.github.io/Portfolio-Website/](https://architasri18.github.io/Portfolio-Website/)

## Features

- Smooth scrolling navigation with active section highlighting
- Light and dark theme toggle (system preference + saved choice)
- Responsive layout and mobile menu
- **About** with education timeline beside bio and certifications
- Skills grouped by backend, frontend, tools, and CS fundamentals
- Project cards with tech tags, live demo, and GitHub links
- Experience and contact sections with social links
- Accessible: skip link, semantic HTML, ARIA labels, visible keyboard focus
- No build step — plain HTML, CSS, and JavaScript

## Tech stack

- HTML5
- CSS3 (custom properties, Flexbox, Grid, media queries)
- Vanilla JavaScript (theme toggle, mobile menu, scroll highlighting)
- [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)

## Run locally

```bash
git clone https://github.com/architaSri18/Portfolio-Website.git
cd Portfolio-Website
npx serve .
```

Open the URL shown in the terminal, or open `index.html` in your browser (a local server is recommended).

## Deploy (GitHub Pages)

1. Push the `main` branch to this repository.
2. On GitHub: **Settings → Pages → Build and deployment → Source:** branch **main**, folder **`/` (root)**.
